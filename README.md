# 🥩 Protein Ledger

**One page. Everything you need to run your protein, supplements & plate.**

Stop guessing your macros. Protein Ledger is a slick, single-page fitness calculator that tells you exactly how much protein you need, what it costs, and how to hit it — no signup, no ads, no BS.

## ⚡ Why you'll like it

- 🧮 **BMI & Protein Calculator** — plug in your stats, get your real number
- 🎯 **Goal Planner** — cut, bulk, or maintain, planned for you
- 🍽️ **Meal Planner** — turn your protein target into an actual plate
- 💰 **Cost Analysis** — compare protein sources by ₹/g so you stop overpaying
- 🌱 **Soy Spotlight & Bioavailability** — the science behind plant vs animal protein, explained simply
- 🏷️ **Trustified Product Picks** — a vetted, no-nonsense supplement shortlist
- 🤖 **AI Prompt Generator** — export your profile as a prompt for ChatGPT/Claude to build a custom plan
- 📚 **Referenced** — every claim backed by a source, not vibes

## 🚀 Quick start

```bash
git clone <your-repo-url>
cd protin-planner-fitness
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and start crunching numbers.

## 🛠️ Tech stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [React 18](https://react.dev/) + TypeScript
- Zero external UI libraries — hand-rolled, fast, clean

## 📁 Project structure

```
app/            # Next.js app router pages & global styles
components/     # All the calculator & content sections
lib/            # Shared state (profile store), calculations & data
research/       # Supporting research notes
```
